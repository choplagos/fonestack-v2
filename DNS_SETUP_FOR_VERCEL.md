# Fonestack canonical domain and sitemap setup

Fonestack is configured to use `https://www.fonestack.com.ng` as its canonical host. DNS values can change, so do not copy an IP address or CNAME target from an old guide. Use the current values shown in the Fonestack Vercel project.

## Verify the domain in Vercel

1. Open the Fonestack project in the Vercel dashboard.
2. Under **Settings → Domains**, confirm that both `www.fonestack.com.ng` and `fonestack.com.ng` are assigned to the project.
3. At the domain registrar, compare the DNS records with the exact values Vercel currently shows. Do not replace nameservers or records unless they match Vercel's current instructions.
4. Deploy the branch containing the canonical-host changes.
5. Check that `https://fonestack.com.ng/` and `https://fonestack.vercel.app/` permanently redirect to the matching path on `https://www.fonestack.com.ng/`, and that a Vercel preview hostname does not redirect.

## Submit the canonical sitemap

After the canonical-host deployment is live:

1. Open Google Search Console for the `fonestack.com.ng` Domain property.
2. Submit `https://www.fonestack.com.ng/sitemap.xml`.
3. Remove the stale `https://fonestack.vercel.app/sitemap.xml?v=1` sitemap entry from the old Vercel property.
4. Request indexing for the homepage, `/budget-smartphone-students-nigeria`, `/blog`, and the priority repair, sell and trade-in pages.
5. Review the sitemap status and indexed-page reports after Google recrawls the site.

The sitemap is generated by [app/sitemap.ts](./app/sitemap.ts). The crawler directive is in [public/robots.txt](./public/robots.txt); there is no separate static sitemap file.

## Google Business Profile

Confirm that Fonestack's Google Business Profile is verified and that its public name, phone number, address, hours and website match the owner's current information. Do not add unconfirmed hours or address details to the site.
